# Aplikasi Pengumuman Kelulusan SDN 40/II Tebing Tinggi

## Isi Folder
- `index.html` — halaman aplikasi utama.
- `assets/logo-sdn-40.png` — logo sekolah lokal.
- `.nojekyll` — file pendukung GitHub Pages.
- `robots.txt` — permintaan agar halaman tidak diindeks mesin pencari.

## Cara Publikasi GitHub Pages
1. Buat repository baru di GitHub, misalnya `pengumuman-kelulusan-sdn40`.
2. Unggah seluruh isi folder ini ke halaman utama repository.
3. Buka **Settings → Pages**.
4. Pada **Source**, pilih **Deploy from a branch**.
5. Pilih branch **main** dan folder **/(root)**, lalu simpan.
6. Buka alamat GitHub Pages yang muncul.

## Catatan Keamanan
Jangan mengunggah file daftar siswa/NISN asli ke repository publik.
Aplikasi statis ini menyimpan pencocokan login sebagai hash, bukan daftar NISN terbuka.
